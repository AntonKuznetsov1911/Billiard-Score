# 🎱 Твой бильярд

Приложение для учёта партий, счёта и статистики в русском бильярде и пуле. Работает в мобильном браузере и как приложение для Android и iOS.

## Возможности

**Игра**
- Русский бильярд и пул, с живым анимированным столом на фоне (удар кием, шар закатывается в лузу)
- 5 дисциплин русского бильярда с правилами: Свободная (Американка), Комбинированная (Московская), Динамичная (Невская), Классическая (71 очко), Колхоз
- Колхоз: игроки сидят по кругу, каждый забивает предыдущему: при порядке Антон, Сергей, Ваня — Антон забивает Ване, Ваня — Сергею, Сергей — Антону. После круга кнопка «Смена позиций» сохраняет счёт и меняет порядок — по умолчанию круг в обратную сторону, любых двух игроков можно поменять местами. Итог партии — расчёт по всем кругам между каждой парой; счёт — очками по номиналу шара (номинал выбирается перед ударом)
- Несколько партий одновременно: за соседними столами или в разных местах — все участники клуба видят все идущие партии, каждый ведёт свою; игрок не может оказаться за двумя столами сразу
- Матчи Best of 3 / 5 / 7 с автоматическим счётом серии
- Фора — личная цель для каждого игрока
- Соло-режим (тренировка): считаются партии и шары, но не искажаются победы
- Бросок кубиков для определения, кто разбивает первым
- Счёт шаров кнопками или вручную; в «71» — номиналы шаров 1–15
- Отмена последних действий (до 5)
- Автоопределение победителя по цели (8 шаров / 71 очко)

**Статистика**
- Партии, победы, поражения, % побед, серии, шары, среднее за игру
- Профессиональный график: победы/поражения + линия % побед
- Рейтинг, лучшие серии, рекорды (самая быстрая победа, самая долгая партия, крупнейший разгром)
- Достижения (серии 5/10, шары 50/100/500, сухая победа, блиц, марафон)
- Личные встречи (head-to-head) между любыми двумя игроками

**Прочее**
- Экран победы с конфетти, кнопками «Реванш» и «Поделиться»
- История партий с деталями, поиск по дате
- Экспорт в Excel, печать в PDF, резервная копия JSON
- «Предложения и ошибки» (вкладка «Ещё»): любой пользователь может сообщить об ошибке или предложить улучшение
- Работает без VPN: шрифты встроены в приложение, к сторонним серверам при запуске оно не обращается
- Тёмная (по умолчанию) и светлая темы
- Шары-аватары игроков

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовые файлы появятся в `dist/` — их можно выложить на любой статический хостинг (GitHub Pages, Vercel, Netlify).

## Публикация как Telegram Mini App (сейчас отключено)

Скрипт Telegram не подключён. Чтобы вернуть Mini App, добавьте в `index.html` строку `<script src="https://telegram.org/js/telegram-web-app.js"></script>` и разрешите этот адрес в политике безопасности в `vite.config.js` (`"script-src 'self' https://telegram.org"`) — код для Telegram (вибро, кнопка «Назад», CloudStorage) уже в приложении и включится сам.

1. Соберите проект и разместите `dist/` на HTTPS-хостинге.
2. В [@BotFather](https://t.me/BotFather): `/newapp` → выберите своего бота → укажите URL приложения.
3. Откройте мини-приложение из бота — haptic-отклик, кнопка «Назад» и тема подхватятся автоматически.

## Хранение данных

Данные (игроки, партии, настройки) хранятся локально на устройстве через `localStorage`. Кнопка «Резервная копия» в разделе «Ещё» позволяет скачать и восстановить все данные файлом JSON.

## Общий доступ (клубы)

По умолчанию выключен. Чтобы несколько игроков видели одни и те же партии и статистику в реальном времени:

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. Выполните `supabase/schema.sql` целиком в Supabase → SQL Editor. Если база уже была создана раньше — выполните вместо этого `supabase/hardening.sql` (права доступа) и `supabase/history.sql` (история изменений клуба; создатель клуба может вернуть любое прежнее состояние).
3. Скопируйте `.env.example` в `.env` и заполните `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (Settings → API → `anon public`, **не** `service_role`) — для локальной разработки. Для GitHub Pages добавьте те же два значения как секреты репозитория (`Settings → Secrets and variables → Actions`) с именами `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` — workflow деплоя уже их подхватывает.
4. Без этих значений раздел «Общий доступ» в приложении просто не отображается — остальной функционал не затронут.
5. Также выполните `supabase/security.sql` (ограничение на подбор кода клуба) и `supabase/feedback.sql` (раздел «Предложения и ошибки»; сообщения читаются в Supabase → Table Editor → `feedback`).
6. Уведомления в Telegram о новых отзывах и ежедневная сводка по пользователям — `supabase/telegram.sql` (инструкция внутри файла; токен бота хранится в Supabase Vault). Сводку можно посмотреть и вручную: `select * from usage_stats();`. Команда `/stats` и кнопка «📊 Статистика» в боте — `supabase/telegram_bot.sql`.
7. Если `*.supabase.co` у пользователей недоступен без VPN — см. `proxy/README.md` (свой домен-прокси).

Вход — по email-ссылке (magic link), без пароля. Один игрок создаёт клуб и получает короткий код, остальные вводят его один раз, чтобы присоединиться. Пока открыт клуб, все партии синхронизируются между участниками через Supabase Realtime.

Ограничения первой версии: личность игрока не проверяется криптографически на сервере (подходит для игры с друзьями, не для защиты чувствительных данных); общее состояние — один JSON-блок на клуб, рассчитан на один живой стол/партию одновременно, а не на несколько параллельных независимых игр в одном клубе.

## Мобильные приложения (Google Play, App Store, RuStore)

Тот же код собирается в нативное приложение через Capacitor (`android/`, `ios/`). Тестовый APK собирает GitHub Actions → «Android build»; подробности, подпись и публикация — в `docs/STORES.md`.
