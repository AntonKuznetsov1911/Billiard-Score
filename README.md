# 🎱 Твой бильярд

Приложение для учёта партий, счёта и статистики в русском бильярде и пуле. Оптимизировано под Telegram Mini App и мобильные браузеры.

## Возможности

**Игра**
- Русский бильярд и пул, с живым анимированным столом на фоне (удар кием, шар закатывается в лузу)
- 5 дисциплин русского бильярда с правилами: Свободная (Американка), Комбинированная (Московская), Динамичная (Невская), Классическая (71 очко), Колхоз
- Колхоз: коллективная игра для 3+ игроков без фиксированной цели — партия завершается вручную, а по итогу для каждой пары считается разница очков (круговая таблица расчёта)
- Матчи Best of 3 / 5 / 7 с автоматическим счётом серии
- Фора — личная цель для каждого игрока
- Соло-режим (тренировка): считаются партии и шары, но не искажаются победы
- Бросок кубиков для определения, кто разбивает первым
- Счёт шаров кнопками или вручную; в «71» — номиналы шаров 1–15
- Отмена последних действий (до 5)
- Автоопределение победителя по цели (8 шаров / 71 очко)

**Статистика**
- Партии, победы, поражения, % побед, серии, шары, среднее за игру
- Профессиональный график: победы/поражения + линия % побед
- Рейтинг, лучшие серии, рекорды (самая быстрая победа, самая долгая партия, крупнейший разгром)
- Достижения (серии 5/10, шары 50/100/500, сухая победа, блиц, марафон)
- Личные встречи (head-to-head) между любыми двумя игроками

**Прочее**
- Экран победы с конфетти, кнопками «Реванш» и «Поделиться»
- История партий с деталями, поиск по дате
- Экспорт в Excel, печать в PDF, резервная копия JSON
- Тёмная (по умолчанию) и светлая темы
- Шары-аватары игроков
- Интеграция с Telegram WebApp: haptic feedback, кнопка «Назад», подтверждение закрытия во время партии

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовые файлы появятся в `dist/` — их можно выложить на любой статический хостинг (GitHub Pages, Vercel, Netlify).

## Публикация как Telegram Mini App

1. Соберите проект и разместите `dist/` на HTTPS-хостинге.
2. В [@BotFather](https://t.me/BotFather): `/newapp` → выберите своего бота → укажите URL приложения.
3. Откройте мини-приложение из бота — haptic-отклик, кнопка «Назад» и тема подхватятся автоматически.

## Хранение данных

Данные (игроки, партии, настройки) хранятся локально на устройстве через `localStorage`. Кнопка «Резервная копия» в разделе «Ещё» позволяет скачать и восстановить все данные файлом JSON. Дополнительно, если открыто внутри Telegram, данные зеркалятся в Telegram CloudStorage.

## Общий доступ (клубы)

По умолчанию выключен. Чтобы несколько игроков видели одни и те же партии и статистику в реальном времени:

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. Выполните `supabase/schema.sql` целиком в Supabase → SQL Editor.
3. Скопируйте `.env.example` в `.env` и заполните `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (Settings → API → `anon public`, **не** `service_role`) — для локальной разработки. Для GitHub Pages добавьте те же два значения как секреты репозитория (`Settings → Secrets and variables → Actions`) с именами `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` — workflow деплоя уже их подхватывает.
4. Без этих значений раздел «Общий доступ» в приложении просто не отображается — остальной функционал не затронут.

Вход — по email-ссылке (magic link), без пароля. Один игрок создаёт клуб и получает короткий код, остальные вводят его один раз, чтобы присоединиться. Пока открыт клуб, все партии синхронизируются между участниками через Supabase Realtime.

Ограничения первой версии: личность игрока не проверяется криптографически на сервере (подходит для игры с друзьями, не для защиты чувствительных данных); общее состояние — один JSON-блок на клуб, рассчитан на один живой стол/партию одновременно, а не на несколько параллельных независимых игр в одном клубе.
