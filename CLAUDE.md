# Инструкции для Claude Code

Этот файл — durable-разрешения для Claude при работе с репозиторием
`Billiard-Score`. Они действуют в любой сессии Claude Code, работающей
с этим репозиторием, не только в той, где были написаны.

## Что разрешено делать без дополнительного подтверждения

- Мержить свои собственные PR (и PR, которые Claude ведёт по просьбе
  пользователя), если у них зелёный CI и нет открытых неразрешённых
  замечаний ревью.
- Пушить исправления в свои собственные ветки/PR, включая ответы на
  автоматические ревью (Codex, CI-боты) и падения проверок.
- Отвечать на комментарии ревью и решать (resolve) обсуждения, если
  замечание исправлено.
- Создавать и обновлять GitHub Actions workflow-файлы, необходимые для
  сборки/деплоя (например `.github/workflows/*.yml`).

## Что делать нельзя без явного разрешения пользователя в моменте

- Менять настройки репозитория (Settings): видимость, Pages source,
  branch protection, вебхуки, интеграции, secrets/variables.
- Форс-пуш в `main`, удаление веток, `git reset --hard` и другие
  деструктивные операции.
- Публиковать что-либо за пределами этого репозитория (другие репо,
  внешние сервисы, соцсети и т.п.).
- Менять зависимости с понижением версии или удалять функциональность
  без явной задачи на это.

## Контекст проекта

«Твой бильярд» — React (Vite) приложение для учёта партий и статистики
в русском бильярде и пуле, с интеграцией Telegram Mini App. Данные
хранятся в `localStorage` на устройстве пользователя.

Деплой — GitHub Pages через `.github/workflows/deploy-pages.yml`
(автосборка и публикация `dist/` при пуше в `main`). Источник Pages в
Settings должен быть выставлен на «GitHub Actions» — это разовая
настройка, которую делает пользователь вручную (у Claude нет доступа
к settings API репозитория).
