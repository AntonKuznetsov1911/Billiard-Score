# Тренировка с упражнениями

Игра → Тренировка с упражнениями. Вид стола соответствует выбранному русскому бильярду или Pool. Пять упражнений: прямой удар, резка, остановка битка, накат и оттяжка. Это базовые удары битком по прицельному шару, а не полный учебник правил каждой дисциплины.

Сетка на схеме помогает перенести расстановку на настоящий стол. Б — биток, пунктирный круг — положение центра битка в момент контакта. Точка на отдельном изображении битка показывает ориентир удара наклейкой. Шары увеличены для читаемости; схема не моделирует физику, трение, упругость бортов и фактическую ширину лузы. Силу и высоту удара нужно подбирать на своём столе. Цели 5–7 из 10 — ориентиры приложения, не официальные нормативы.

Десять попыток, ручная отметка успеха, отмена последней попытки, автоматическое сохранение незавершённого подхода. Игрок необязателен. Каталог показывает лучший завершённый подход для выбранного игрока и вида игры. Прежний свободный соло-счёт сохранён.

Хранение: practiceSessions в общем JSON рабочего пространства. В гостевом режиме на устройстве; личный профиль и клуб используют прежние механизмы синхронизации с независимыми данными. В клубе результаты упражнений доступны участникам клуба. Экспорт и восстановление включают тренировки. Удаление всех данных очищает их с practiceResetAt, старые копии при обычной синхронизации не воскрешают подходы. Явное восстановление резервной копии действует как раньше через restoreAt. Матчи, рейтинг и соревновательные рекорды упражнениями не изменяются.

Слияние объединяет подходы по ID, попытки по ID и отмены по ID; отображаются первые десять неотменённых попыток. До 2000 подходов, до 100 нажатий результата на подход с учётом отмен; затем нужно начать новый подход. Прежний серверный лимит JSON 2 МБ остаётся действующим, ошибка синхронизации сообщается существующим механизмом. Новых таблиц, разрешений и серверных миграций нет.

Основа объяснений: Dr. Dave, https://drdavepoolinfo.com/faq/stun/stop/ ; Sport Singapore, https://www.activesgcircle.gov.sg/learn/billiards-and-snooker/cuesport-different-types-of-shots . Текст подсказок написан для приложения, сторонние изображения не используются. Остановка требует отсутствия вращения именно к моменту столкновения; удар в центр сам по себе этого на любой дистанции не гарантирует.
